# Architecture Decision Records

Create an ADR only for a meaningful architectural decision.

Use a numbered Markdown file such as `0001-short-decision-name.md` with this
required structure:

1. **Status** — proposed, accepted, superseded, or rejected.
2. **Context** — the forces and constraints behind the decision.
3. **Decision** — the chosen approach.
4. **Consequences** — positive and negative outcomes.
5. **Alternatives considered** — credible options and why they were not chosen.
